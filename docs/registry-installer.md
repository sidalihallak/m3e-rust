# Installing editable components

Run from this repository with Python 3.11 or newer. The installer is a local
checkout CLI; a published remote registry or Cargo installer is not provided yet.

```sh
python3 scripts/m3e.py list
python3 scripts/m3e.py plan button text-field material-symbol --target /path/to/app
python3 scripts/m3e.py add button text-field material-symbol --target /path/to/app
# Complete kit:
python3 scripts/m3e.py add --all --target /path/to/app
```

The installer creates an editable `ui-kit/` library, resolves component helpers,
CSS, JavaScript, icons and theme dependencies, and writes a content hash lock.
Add this dependency to your application's Cargo.toml:

```toml
[dependencies]
m3e-rust-ui = { path = "ui-kit" }
```

Import `m3e_rust_ui::*`, render `UiStyles {}` once, and apply color variables
from `theme::Theme` to an ancestor. `UiStyles` is generated by the installer.
See [the independent application](../examples/consumer/src/main.rs) for a full
Dioxus example and [its setup](../examples/consumer/README.md). Gallery CSS and
Tailwind are not required. The consuming app chooses the Dioxus platform.

```sh
python3 scripts/m3e.py status --target /path/to/app
python3 scripts/m3e.py update --target /path/to/app
```

Updates preserve local files when the upstream source is unchanged. Conflicting
upstream/local changes and unmanaged destinations stop before writes. Review
`plan`, use `--dry-run`, and explicitly use `--overwrite` only when discarding
local changes is intended. Writes are atomic per file, not a whole-directory
transaction. The installer does not modify your app's Cargo.toml automatically.

After editing kit source, regenerate `registry/registry.json` with
`python3 scripts/build-registry.py`. A stale manifest is rejected.

See [installer verification](registry-installer-verification.md).

## Versioned GitHub distribution

A deterministic source archive and GitHub release workflow are prepared.
See [GitHub release instructions](github-registry-release.md) for public/private
access, download/checksum steps and draft publication. Hosted releases require
a pushed version tag and successful CI; no release has been published by this work.
