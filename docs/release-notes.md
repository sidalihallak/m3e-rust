# M3E Rust UI 0.1.0 — preview release

Editable Dioxus Material 3 Expressive component sources, a selective installer,
semantic color themes and local Material Symbols assets.

- 76 public registry entries with dependency resolution.
- 4,301 pinned icon names across three families and two fill states.
- Source archive includes the Python installer, registry and file checksums.
- Independent consuming-app fixture and source/browser verification workflows.

This is a preview API. Native Dioxus platforms, Android touch, audible screen
readers, full RTL and complete upstream engine parity remain open. Check
component verification reports before relying on a particular interaction.

Download the source archive and SHA256SUMS, verify the checksum, extract it,
and run `python3 scripts/m3e.py add ... --target /path/to/app`. See
`docs/registry-installer.md` inside the archive for setup and local edit rules.
